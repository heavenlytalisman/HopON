# HopON

HopON is a clean, minimalistic cross-platform mobile application that allows you to instantly alert your friend groups (squads) to hop on Discord and play games like Valorant, CS2, or League of Legends.

**Developed with Antigravity AI.**

## Features
- **Anonymous Authentication**: Instantly join with a nickname.
- **Squad System**: Create or join friend groups seamlessly.
- **Instant Alerts**: High-priority push notifications to wake up your squad.
- **Cross-Platform**: Built with React Native (Expo) for iOS and Android.

## Tech Stack
- Frontend: React Native (Expo)
- Backend: Firebase Firestore
- Authentication: Firebase Anonymous Auth
- Notifications: Expo Push Notifications

## Getting Started

### Prerequisites
- Node.js
- Expo CLI
- Expo Go App on your mobile device

### Installation
1. Clone the repository.
2. Run `npm install` (or `npm.cmd install` on Windows).
3. Run `npx expo start` (or `npx.cmd expo start`).
4. Scan the QR code using the Expo Go app.
